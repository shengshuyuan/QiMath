# QiMath 改动记录

按时间倒序。当前使用说明与技术约定见 [AI_readme.md](../AI_readme.md)。

## 2026-11-07 · 更好用、更好玩、更会说

- **首页看得见进度**：学过的课程卡上显示进度条、已完成关数 / 知识点数和错题数；有错题时首页顶部出现「有 N 道错题等着复习」横幅，一键进入错题最多的那门课。
- **找错游戏扩展到所有专题课**：新增 `js/topic-games.js`「找出算错的小捣蛋」，混合运算、长度、角、时间、质量、人民币的练一练页都能玩。题目全部来自各课程现成的出题器，只把其中一张卡的答案改错；带图的题自动跳过。
- **语音**：系统合成朗读前把 `＝ ＋ － × ÷`、`8:25`、`cm / kg` 等改写成口语（`MT.speech.spoken`）；「听方法」只读讲解正文，不再念图里的刻度数字；设置中新增「下载这门课的真人语音」，让 Service Worker 一次缓存当前运算的全部录音（约 5 MB），断网也能听。
- **更简单**：练习准备页只保留一句关键提醒；设置里的进度迁移改为「保存进度文件 / 读取进度文件」并配一句话说明；离线语音、换设备两组设置用细线分组。
- **题目逻辑**（`js/time.js`）：时间换算不再出现「1 时 0 分」；经过时间的讲解对整时开始 / 结束分别给出合理步骤；钟面读法讲解按「分针指向几 = 几个 5 分」说明，干扰项贴近真实错误（把分针指的数字当分钟数）。
- **代码**：人民币专属样式拆到 `css/money.css`；新增 `tools/check-pages.js`（无头 Chrome 渲染 80 个页面，检查 JS 报错、横向溢出、按钮尺寸）和 `tools/check-topic-games.js`；`check-speech` 增加口语改写用例；`check-navigation` 覆盖新的游戏路由。
- 版本：改动文件 `2.7.0`，离线缓存 `mt99-cache-v45`。

## 2026-11-06 · 学习进度备份与域名迁移

设置中新增导出 / 导入学习进度。从旧网址导出 JSON 后，在新网址导入；所有课程、错题、星级、勋章和设置一起迁移。导入前验证文件格式并确认替换，写入失败保留原进度；导入前状态另保存在同浏览器的 `mt99.progress.v1.before-import`，内容也是可导入的备份格式。仅支持 QiMath 导出的 2 MB 以内 JSON，不会自动跨域同步或合并多设备记录。脚本版本 `2.6.10`，离线缓存 `mt99-cache-v44`。

## 2026-11-05 · 全站共用界面

加减乘除的闯关页把「重置闯关」和关卡说明放在同一行，闯关进行中仍可点「重置闯关」。错题为空时给出说明卡片并可直接去练一练。勋章说明不再被裁成一行。设置里的「重置全部进度」和上面的开关用细线隔开。次要按钮和分段开关的点按高度统一为 44 像素。样式版本 `2.6.9`（基础样式 `2.6.8`），离线缓存 `mt99-cache-v44`。

## 2026-11-05 · 目录页层级

知识目录沿用原有按钮和颜色，不引入界面库。课程符号改成同样大小的浅紫方块，分组标题和说明分成两行，底部「关于树园」改为细线下的说明文字。样式版本 `2.6.8`，离线缓存 `mt99-cache-v41`。

## 2026-10-16 · 审查修复

1. **人民币进度刷新丢失（严重）**：`js/storage.js` 加载主题时只认 `mixed` / `length`，漏了 `money`。已纳入白名单并恢复 `games`。
2. **「不进退位」加减只有减法**：`mode === 1` 时加法支路是死代码。已改为独立开关，并保证加法各位之和 < 10。
3. **数钱讲解漏「分」**：拼钱币托盘时改写了 `f`，讲解里分的部分常被吃掉。已用临时变量拆分。

七项 `tools/check-*.js` 全部通过。`CACHE_NAME` → `mt99-cache-v31`，资源版本 `2.5.4`。
