# QiMath · 启数乐学

> **启蒙数理，乐学善思 —— 看得见的小学数学探究与互动平台**

专为小学生打造的**可视化、强交互、无广告**数学探索学习工具。不依赖死记硬背，而是让每一个数学算式与概念都变成“看得见、摸得着”的趣味互动图示与动手游戏。

---

## 🌟 核心板块与玩法

| 板块 | 功能亮点 |
|---|---|
| 🔍 **探究台** | 从知识目录进入**加、减、乘、除**课程。乘法自选因数，生成阵列、分组、数轴、方格，可换实物皮肤，并交换因数。除法用同一张图看「平均分」或「几个一份」。加法用两种颜色把两部分合在一起，数轴向右跳，并说明凑十。减法留下原来的数量、划走拿走的部分，数轴向左跳，并说明破十。数字不能越界。 |
| 📋 **口诀表** | 乘法可在三角 45 式和完整 81 格之间切换。除法是 81 道表内算式。加减法按和或被减数一次看一组，避免整张大表。点开可听完整算式、看图、标记已掌握或需再练。加法交换顺序共用一条掌握记录。 |
| 🏆 **趣味闯关** | 乘除各 9 关，20 以内加减各 6 关。仍是 3 次挑战机会、2 次求助和数字键盘。每轮最多 10 道本关题，再加最多 4 道已学过、需要复习的题。错题本按运算分开记。 |
| 🎈 **游乐场** | 气球游戏按当前运算寻找指定的和、差、积或商。捣蛋鬼游戏找出写错的算式，并给出纠正说明。 |
| 🪄 **混合运算** | 加减混合、乘除混合、先乘除后加减和小括号。20 / 100 以内分层，每题先选运算顺序，再算中间值和最终结果。乘除使用表内整数，不出现负数、分数或除以零。 |
| 📏 **米和厘米** | 认识 m / cm、选合适单位、从 0 和非 0 起点读尺、统一单位比较长度，以及 1～9 米与 100～900 厘米的整米换算。尺图为示意，实际长度请观察真实尺子。 |
| 💴 **认识人民币** | 认识元角分与常见面值，读写标价、换算、比较大小、简单加减，以及购物找零。练习页另有「凑钱小能手」「小小收银员」趣味游戏。 |
| 🎖️ **荣誉勋章馆** | 8 枚精心设计的进阶成就勋章（如启程小星、气球大王、神探火眼、乘法大师等），解锁即伴随弹幕气泡与庆祝礼花，激发儿童自驱力。 |

课程页右上角辅助工具：**勋章馆**、**真人普通话朗读开关**、**A4 口算卡与空表一键排版打印**、**个性化设置**。

知识目录按 **数与运算 / 量与测量** 分组，提供加法、减法、乘法、除法、混合运算、米和厘米、认识人民币七门课程。所有课程共用 **学一学 / 练一练 / 错题**：探究和口诀放在学习中，闯关和游戏放在练习中。手机知识点目录可展开选择，答题时收起；混合运算与人民币范围在练习准备页选择，乘除混合固定为表内整数。

地址记录当前课程、知识点和学习方式，支持刷新、浏览器返回与前进；目录可继续上次位置。刷新练习时回到准备页，不重复计分。新课程每轮练习 6 题，答错或看过提示的题保留用于复习，连续两次独立答对后移出错题本。打印跟随当前课程和知识点，可在设置中附加答案页。

## 🚀 极简免安装与离线使用

- **零依赖极速打开**：纯原生 HTML5 / CSS3 / ES6 构建，无任何第三方重量级框架与打包构建门槛，双击 `index.html` 即可完整体验。
- **PWA 桌面级应用**：已配置完整的 `manifest.json` 与 Service Worker 缓存，可在 iPad、iPhone、Android 手机或平板上一键“添加到主屏幕”，全屏无浏览器地址栏，支持完全离线运行。

---

## 🎧 自然普通话与触感体验

- **真人普通话原声音频**：内置 macOS 婷婷录音，按原句对应乘法口诀、乘除算式和 20 以内加减算式。没播过的录音不保证断网后还能听；没有录音时，文字学习和做题仍然可用。
- **新知识朗读**：混合运算和长度课程复用现有语音入口，动态内容使用浏览器的系统朗读；音色及离线发声取决于设备。
- **多层次音效设计**：基于 Web Audio API 纯代码实时振荡合成（答对轻快上行、答错温柔提示、通关庆祝旋律、戳气泡波波声），轻巧优雅不占带宽。
- **多端轻量触觉反馈**：支持设备原生短震动反馈（按键微震、答对双震、失误轻震），在手机端更具物理打击感。
- **3D 拟物厚键反馈**：全站按钮采用类似 Duolingo 的 Q 弹厚底实体按键效果（下压 2-3px），操作手感饱满。

## 🛠️ 未来规划（小学数学综合平台）

### 扩展约定

设计与内容约定见 [DESIGN.md](DESIGN.md)。保留 `MT.op` 管理基础运算；新知识模块提供 `id / title / subtitle / skills / generate`，由 `topics.js` 共用课程、数字/选择/分步题、错题与打印流程。错题保存知识点、范围和种子，显示时重建题目；新增进度在 `topics` 下分主题保存，旧版记录无需整体迁移。只有实际出现新的交互需求时才扩充题型。

增加知识主题时，同步更新入口、模块加载、本地数据读取和 `sw.js` 预缓存。当前回归检查：

```sh
node tools/check-add-sub.js
node tools/check-mixed.js
node tools/check-length.js
node tools/check-topics.js
node tools/check-navigation.js
node tools/check-sw-precache.js
node tools/check-money.js
```

使用与部署说明（含线上地址）见 [AI_readme.md](AI_readme.md)。
