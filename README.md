# QiMath · 启数乐学

让小学数学从“背答案”变成“看图理解、动手练习”。QiMath 面向小学生、陪学家长和教师，把基础运算、时间、长度、质量与人民币知识组织成可视化学习、分步练习和错题复习。

[打开网页版](https://qimath.vercel.app) · [使用与部署说明](AI_readme.md)

![QiMath 从知识学习到错题复习的流程](docs/images/project-overview.svg)

*功能流程示意，非界面截图。*

## 适合怎么用

- **孩子自主练习**：选一门课程、一个知识点，先学一学，再完成短轮练习。
- **家长陪学**：用阵列、分组、数轴、钟面等图示解释思路，再根据错题补练。
- **课堂与纸面练习**：按当前课程生成 A4 题单，可选附答案页。

**从这里开始**：选择课程 → 看图理解 → 做一轮练习 → 回到错题巩固。学习进度保存在当前浏览器，不提供账号或跨设备同步；清理浏览器数据前请留意进度丢失风险。

## 🌟 核心板块与玩法

| 板块 | 功能亮点 |
|---|---|
| 🔍 **探究台** | 从知识目录进入**加、减、乘、除**课程。乘法自选因数，生成阵列、分组、数轴、方格，可换实物皮肤，并交换因数。除法用同一张图看「平均分」或「几个一份」。加法用两种颜色把两部分合在一起，数轴向右跳，并说明凑十。减法留下原来的数量、划走拿走的部分，数轴向左跳，并说明破十。数字不能越界。 |
| 📋 **口诀表** | 乘法可在三角 45 式和完整 81 格之间切换。除法是 81 道表内算式。加减法按和或被减数一次看一组，避免整张大表。点开可听完整算式、看图、标记已掌握或需再练。加法交换顺序共用一条掌握记录。 |
| 🏆 **趣味闯关** | 乘除各 9 关，20 以内加减各 6 关。仍是 3 次挑战机会、2 次求助和数字键盘。每轮最多 10 道本关题，再加最多 4 道已学过、需要复习的题。错题本按运算分开记。 |
| 🎈 **游乐场** | 气球游戏按当前运算寻找指定的和、差、积或商。捣蛋鬼游戏找出写错的算式，并给出纠正说明。 |
| 🪄 **混合运算** | 加减混合、乘除混合、先乘除后加减和小括号。20 / 100 以内分层，每题先选运算顺序，再算中间值和最终结果。乘除使用表内整数，不出现负数、分数或除以零。 |
| 📏 **长度单位** | 认识 m / cm、选合适单位、从 0 和非 0 起点读尺、统一单位比较长度，整米换算、认识和画线段、统一单位做长度加减。尺图为示意，实际长度请观察真实尺子。 |
| ∠ **角的初步认识** | 认识顶点和边，比较张口大小，区分直角、锐角与钝角；角的大小与边画得长短无关。 |
| ◷ **认识时间** | 认识钟面与时针分针、读写时分、时分换算和简单经过时间。 |
| ⚖ **克和千克** | 选择 g / kg、称量估计、1 千克＝1000 克换算，以及统一单位比较质量。 |
| 💴 **认识人民币** | 认识元角分与常见面值，读写标价、换算、比较大小、简单加减，以及购物找零。练习页另有「凑钱小能手」「小小收银员」趣味游戏。 |
| 🎖️ **荣誉勋章馆** | 14 枚勋章：保留原 8 枚，新增混合运算、长度、角、时间、质量、人民币六枚主题勋章。显示解锁条件与知识点进度，每个知识点至少独立答对 1 题后获得对应主题勋章。 |

课程页右上角辅助工具：**勋章馆**、**普通话朗读开关**、**A4 口算卡与空表一键排版打印**、**个性化设置**。

知识目录按 **数与运算 / 量与测量** 分组，提供加法、减法、乘法、除法、混合运算、长度单位、角的初步认识、认识时间、克和千克、认识人民币十门课程。所有课程共用 **学一学 / 练一练 / 错题**：探究和口诀放在学习中，闯关和游戏放在练习中。手机知识点目录可展开选择，答题时收起；混合运算与人民币范围在练习准备页选择，乘除混合固定为表内整数。

地址记录当前课程、知识点和学习方式，支持刷新、浏览器返回与前进；目录可继续上次位置。刷新练习时回到准备页，不重复计分。知识主题通常每轮练习 6 题；认识角为 2 题、角的易错辨析为 3 题，避免小题库被迫重复。提示先展示思路，再可展开完整解答；提前结束会显示已完成数量。答错或看过提示的题保留用于复习，连续两次独立答对后移出错题本。打印跟随当前课程和知识点，可在设置中附加答案页。

## 🚀 极简免安装与离线使用

- **无需前端构建**：使用原生 HTML / CSS / JavaScript。建议通过线上地址或本地 HTTP 服务打开；直接打开文件不具备完整 PWA 缓存能力。

  ```sh
  python3 -m http.server 8080
  ```

  浏览器访问 `http://localhost:8080`。
- **PWA 桌面级应用**：已配置 `manifest.json` 与 Service Worker，可在支持的浏览器中添加到主屏幕。先联网访问并完成缓存后可离线学习；录音缓存、系统朗读、震动和打印效果依设备而异。

## 🎧 自然普通话与触感体验

- **真人普通话原声音频**：内置 macOS 婷婷录音，按原句对应乘法口诀、乘除算式和 20 以内加减算式。没播过的录音不保证断网后还能听；没有录音时，文字学习和做题仍然可用。
- **新知识朗读**：混合运算和长度课程复用现有语音入口，动态内容使用浏览器的系统朗读；音色及离线发声取决于设备。
- **多层次音效设计**：基于 Web Audio API 纯代码实时振荡合成（答对轻快上行、答错温柔提示、通关庆祝旋律、戳气泡波波声），轻巧优雅不占带宽。
- **多端轻量触觉反馈**：支持设备原生短震动反馈（按键微震、答对双震、失误轻震），在手机端更具物理打击感。
- **3D 拟物厚键反馈**：全站按钮采用类似 Duolingo 的 Q 弹厚底实体按键效果（下压 2-3px），操作手感饱满。

## 🛠️ 未来规划（小学数学综合平台）

### 扩展约定

设计与内容约定见 [DESIGN.md](DESIGN.md)。保留 `MT.op` 管理基础运算；新知识模块提供 `id / title / subtitle / skills / generate`，由 `topics.js` 共用课程、数字/选择/分步题、错题与打印流程。错题保存知识点、范围和种子，显示时重建题目；新增进度在 `topics` 下分主题保存，旧版记录无需整体迁移。只有实际出现新的交互需求时才扩充题型。

增加知识主题时，同步更新入口、模块加载、本地数据读取和 `sw.js` 预缓存。当前回归检查：

```sh
node tools/check-add-sub.js
node tools/check-mixed.js
node tools/check-length.js
node tools/check-measurements.js
node tools/check-topics.js
node tools/check-navigation.js
node tools/check-sw-precache.js
node tools/check-money.js
node tools/check-money-games.js
```

使用与部署说明（含线上地址）见 [AI_readme.md](AI_readme.md)。
