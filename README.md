# QiMath · 启数乐学

> **启蒙数理，乐学善思 —— 看得见的小学数学探究与互动平台**

专为小学生打造的**可视化、强交互、无广告**数学探索学习工具。不依赖死记硬背，而是让每一个数学算式与概念都变成“看得见、摸得着”的趣味互动图示与动手游戏。

---

## 🌟 核心板块与玩法

| 板块 | 功能亮点 |
|---|---|
| 🔍 **探究台** | 自选因数（1-9 按键或滑块），实时生成**阵列点阵、分组积木、数轴跳跃、面积方格** 4 种可视化形态；同步呈现连加与乘法算式，一键「交换因数 ⇄」直观体悟乘法交换律。 |
| 📋 **口诀表** | 支持**三角 45 式（小九九）**与**完整 81 格**形态自由切换；点击格子即时展开直观图示并播报标准普通话语音，可标记「已掌握 / 需再练」。 |
| 🏆 **趣味闯关** | 渐进式关卡体系，融合当关口诀与错题复习；智能求助与容错引导机制；通关斩获星星徽章，自动收录错题本。 |
| 🎈 **游乐场（全新）** | <ul><li>**气球爆破**（逆向因数找朋友）：根据目标乘积戳破对应因数气球，训练逆向拆解与分解思维。</li><li>**找出捣蛋鬼**（挑错大侦探）：精选小学高频 15 组经典易错乘法陷阱，抓出算错的算式并纠正强化。</li></ul>*(支持全局内存缓存，随意切换标签不丢进度)* |

右上角常驻辅助工具：**真人普通话朗读开关**、**A4 口算卡与空表一键排版打印**、**个性化设置**。

## 🚀 极简免安装与离线使用

- **零依赖极速打开**：纯原生 HTML5 / CSS3 / ES6 构建，无任何第三方重量级框架与打包构建门槛，双击 `index.html` 即可完整体验。
- **PWA 桌面级应用**：已配置完整的 `manifest.json` 与 Service Worker 缓存，可在 iPad、iPhone、Android 手机或平板上一键“添加到主屏幕”，全屏无浏览器地址栏，支持完全离线运行。

---

## 🎧 自然普通话与触感体验

- **真人普通话原声音频**：内置 250+ 条高保真录音（macOS 婷婷原声），发音标准自然，告别机械生硬的机器人语音；严格屏蔽方言混淆。
- **多层次音效设计**：基于 Web Audio API 纯代码实时振荡合成（答对轻快上行、答错温柔提示、通关庆祝旋律、戳气泡波波声），轻巧优雅不占带宽。
- **多端轻量触觉反馈**：支持设备原生短震动反馈（按键微震、答对双震、失误轻震），在手机端更具物理打击感。

## 📂 项目结构

```
QiMath/
├── index.html          # 主页面结构
├── manifest.json       # PWA 应用配置
├── sw.js               # Service Worker 离线缓存服务
├── icon.svg            # 矢量应用图标
├── vercel.json         # Vercel 部署配置
├── audio/piper/        # 预录高保真普通话口诀与算式音频 (250+ mp3)
├── css/
│   ├── base.css        # 全局设计规范与治愈系色彩变量
│   ├── layout.css      # 响应式布局与导航栏
│   ├── visuals.css     # 点阵/积木/数轴/面积方格等可视化样式
│   ├── quiz.css        # 闯关答题、数字键盘与错题本
│   ├── games.css       # 游乐场（漂浮气球、捣蛋鬼卡片、结算卡）
│   └── print.css       # A4 练习卡打印专用黑白矢量样式
├── js/
│   ├── core.js         # 数学核心运算、口诀字典、随机算法
│   ├── storage.js      # 本地持久化存储与掌握度记录
│   ├── voice-clips.js  # 音频字典映射
│   ├── speech.js       # 智能普通话语音播报控制
│   ├── sound.js        # Web Audio 音效实时合成器
│   ├── visuals.js      # 4 大可视化模型 Canvas/DOM 渲染引擎
│   ├── explore.js      # 探究台交互逻辑
│   ├── table.js        # 45/81 口诀表交互与详情弹窗
│   ├── quiz.js         # 关卡答题流转与错题逻辑
│   ├── games.js        # 气球爆破与找出捣蛋鬼小游戏逻辑
│   ├── print.js        # A4 口算题单动态生成与打印
│   └── app.js          # 全局生命周期与各模块协同入口
└── tools/
    └── build-piper-voice.py # 音频预处理工具脚本
```
